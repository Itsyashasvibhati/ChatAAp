# 💬 Real-Time Chat App

A simple and responsive real-time chat application built using **Node.js**, **Express**, **Socket.IO**, and **JavaScript**. Users can join chat rooms and communicate instantly with others.

## 🚀 Features

- 🔐 User authentication (optional)
- 🧑‍🤝‍🧑 Join custom chat rooms
- 📩 Real-time messaging using WebSockets
- 🧠 Typing indicators
- 🌙 Light/Dark mode (optional)
- 🔒 Secure and scalable backend
- 📱 Responsive design (mobile-friendly)

## 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Real-Time Communication: Socket.IO
- (Optional) Database: MongoDB + Mongoose for message storage
- (Optional) Authentication: Passport.js / JWT
