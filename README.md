# 💬 Java Client-Server Messenger 

Welcome To My ChatApp!

Let's Talk!


A **Java Swing–based Client-Server Messenger Application** built using **Socket Programming** that supports **real-time text messaging** between a client and a server with a clean graphical user interface.

---

## 🚀 Features

* 🔗 **Client–Server Communication** using Java Sockets
* 💬 **Real-time Chat Messaging**
* 🖥️ **GUI using Java Swing** (Client & Server)
* 🧵 **Multithreaded Architecture** (simultaneous read/write)
* ⚡ Lightweight & fast local network communication

---

## 🛠️ Technologies Used

* **Java (Core Java)**
* **Socket Programming**
* **Java Swing (GUI)**
* **Multithreading**
* **I/O Streams**
* **AWT Events**

## ▶️ How to Run the Project

### 1️⃣ Compile the files

```bash
javac Server.java
javac Client.java
```

### 2️⃣ Start the Server

```bash
java Server
```

### 3️⃣ Start the Client

```bash
java Client
```

> ⚠️ Make sure both run on the same system or same network.
